# Sun SVG alternatives

Open Preview.html to compare 16, 20, 24 and 32 pixel rendering on light and dark backgrounds.

- 01-classic-sun.svg: an original twelve-point sun inspired by the supplied Windows emoji reference.
- 02-minimal-sun.svg: an original circular face with eight separate rays.
- 03-microsoft-sun.svg: Microsoft's Fluent Emoji High Contrast sun, with eyebrows removed, normalized painted bounds and currentColor. This is a later Microsoft design, not the exact Windows 10 emoji.

All three use a 24 by 24 viewBox, centered painted geometry, transparent background and currentColor. Standalone files render black by default; when embedded inline in Obsidian they inherit the interface color. No fonts, raster images, scripts or external resources are required by the SVG files.

Microsoft source: https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/Sun%20with%20face/High%20Contrast/sun_with_face_high_contrast.svg
